# 🌸 Sitio Web - Vivero & Venta de Flores

Este repositorio contiene la pre-entrega de la **Clase 08**, desarrollada como un sitio web estático para un emprendimiento de venta de flores y plantas.

## 🚀 Tecnologías y Características
- **HTML5 Semántico**: Uso de etiquetas estructurales (`header`, `nav`, `main`, `section`, `footer`).
- **CSS3 Externo**: Estilos personalizados aplicando **Google Fonts**.
- **Diseño Responsive**: 
  - Sección de Productos organizada mediante **Flexbox**.
  - Sección de Reseñas estructurada con **CSS Grid**.
  - Adaptabilidad para diferentes pantallas utilizando **Media Queries**.
- **Formulario de Contacto**: Integrado con **Formspree** para la recepción de mensajes.
- **Multimedia**: Inclusión de contenido de video y recursos visuales.
